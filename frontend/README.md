# Frontend - Sistema de Trazabilidad de Calzado

## Descripción

Frontend desarrollado en React para la gestión y trazabilidad de órdenes de fabricación de calzado.

## Tecnologías

* React
* Vite
* React Router DOM
* Axios

## Instalación

```bash
cd frontend
npm install
```

## Ejecución

```bash
npm run dev
```

Aplicación disponible en:

```text
http://localhost:5173
```

## Estructura del Proyecto

```text
src/
├── components/
├── pages/
├── router/
├── services/
└── styles/
```

## Módulos

* Dashboard
* Productos
